# 🛠️ Install BakeKit

Follow the steps below to install **BakeKit**, a modular CakePHP 5-based web application starter kit with support for plugins, themes, widgets, and more.

---

## 📦 Requirements

Make sure your environment meets the following:

- PHP **8.3+**
- [Composer](https://getcomposer.org/)
- A web server (e.g., Apache or Nginx)
- A database (MySQL, MariaDB, etc.)

---

## 🚀 Installation

```bash
composer create-project bakewizard/bakekit myapp
cd myapp
curl -sS https://getcomposer.org/installer | php -- --install-dir=bin
bin/cake install
bin/cake server
```
