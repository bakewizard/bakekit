# 🎉 Welcome to BakeKit

**BakeKit** is a modern web application boilerplate built with **CakePHP 5**, featuring a clean Admin Panel and everything you need to get started fast.

Core features include:

- 🔐 Authentication with Roles & Permissions
- 🔌 Plugin loader (ZIP upload with Composer support)
- 🎨 Theme system with Regions & Blocks
- 🧩 Widget (Cell) support
- ⚙️ Settings, Menus, Slideshow, Pages, Blog
- 📄 Fully open-source (MIT Licensed)

> **Start fast. Build easily. Customize deeply.**
